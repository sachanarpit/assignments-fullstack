# Candidate Engagement Chatbot

![Candidate Engagement Bot System Design](https://raw.githubusercontent.com/sachanarpit/assignments-fullstack/c1d7dcf70546c3081e7fc99e6ea3745a4b7bda90/system_design.svg)

## Overview

This project implements a specialized chatbot designed to engage job applicants with contextually relevant information while qualifying their fit for positions. The system provides natural conversation flow while extracting key candidate information and maintaining context throughout the interaction.

## Features

- 🤖 Natural conversation interface for job-related queries
- 📝 Contextual responses based on specific job descriptions
- 🎯 Intelligent candidate qualification extraction
- 📊 Structured candidate profile generation
- 🔄 Conversation state management
- 💡 LLM-powered natural language understanding

## Technical Stack

- Frontend: React with TypeScript
- Backend: Node.js with TypeScript
- AI Integration: OpenAI GPT API
- State Management: Custom conversation context handler
